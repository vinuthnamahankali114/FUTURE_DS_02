# Customer Retention & Churn Analysis Dashboard

## Project Overview
This project analyzes customer churn and retention using Excel. The dashboard provides insights into customer behavior, contract types, payment methods, and monthly charges.

## Key Metrics
- Total Customers: 7033
- Churn Customers: 1865
- Retained Customers: 5168
- Churn Rate: 26.52%

## Key Insights
1. Month-to-month contract customers show the highest churn.
2. Customers using electronic check payment methods churn more frequently.
3. Customers with higher monthly charges tend to leave faster.
4. Long-term contracts improve customer retention.

## Recommendations
1. Offer discounts for yearly subscriptions.
2. Improve support for high-risk customers.
3. Introduce loyalty rewards and retention offers.
4. Reduce pricing pressure through bundled plans.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts & Dashboarding
